Checking…

First run: choose the password for this Optimux. To prove you own the server, paste the access token. It was printed when the server first started and is in ~/.optimux/secrets.env as OPTIMUX_TOKEN.

Forgot the password? On the server, delete ~/.optimux/auth.json and reload this page: you can set a new one with the access token.

This page is not using HTTPS. Anyone on the network path can read the password. Use HTTPS (see the Guide, "Running on a server") unless this is your own computer.
