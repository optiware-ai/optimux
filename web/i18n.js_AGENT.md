# i18n.js Agent Details

## File Overview
`web/i18n.js` (v0.8) is the page's language support, loaded before `app.js`. English is the source: every text is written in English in `index.html` and `app.js`; another language is a JSON file `web/i18n/<code>.json` mapping the English text to its translation. A text missing there shows in English.

## Core Functionality
- `LANGS`: the languages offered (`en`, `it`), with their names. Must match `config_manager.LANGUAGES` (a test checks).
- `tr(text, vars)`: the translation, with `{name}` placeholders filled from `vars`. A translation may leave a placeholder out (an English plural `s`). Reads the reactive `lang` and `messages`, so templates re-render on a change.
- `trh(text, vars)`: the same for text with inline markup shown through `v-html`; every value is HTML-escaped first, so a project name or path can never inject markup.
- `tk(text)`: returns the text unchanged; marks a text kept as data (a menu label) so the test finds it, and the template shows it with `$t(item.label)`.
- `setLanguage(code)`: loads `/static/i18n/<code>.json` once, switches, sets `<html lang>` and remembers it in this browser (`optimux.lang`), so the next load starts in that language before the settings arrive. It doesn't save on the server.
- `window.OptimuxI18n = { LANGS, lang, tr, trh, setLanguage }`; `window.tr`, `trh`, `tk`. `app.js` registers `$t` and `$th` as global template helpers.

## Links & Dependencies
- Saving: `chooseLanguage` in `app.js` → `POST /api/language` (`config_manager.set_language`); `GET /api/settings` returns `language`, and `POST /api/settings` never changes it. `/auth/status` returns it too, for the sign-in page (`web/login.js`, which translates elements marked `data-i18n` by their inner HTML).
- Components in `app.js`: `LangFlag` (drawn SVG flags: emoji flags don't show on every system), `LangBadge` (the flag button and its menu).
- Tests: `tests/test_i18n.py` (every marked text in `index.html`, `app.js`, `i18n.js`, `login.js` and `login.html` has its translation, placeholders match, no unused entries, the endpoint).
- The Guide's *Language* section.
