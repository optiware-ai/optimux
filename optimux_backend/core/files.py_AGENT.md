# files.py

`write_file` and `edit_file`, the models' tools for changing files (v0.4-5i). They replace writing files through shell here-docs, which emptied a file, ate quotes and looped on quoting during the plan-mode measurement.

- **Scope (the safety boundary):** `resolve_target(project, path)` follows symlinks (`os.path.realpath`) and refuses a target outside the project, the project folder itself, anything with a `.git` path part, anything in Optimux's data folder (`paths.HOME`), folders, empty paths and NUL characters. These tools run in Optimux, not in the bubblewrap sandbox, so this check is what keeps them in the project.
- **Prepare, then apply:** `prepare_write(project, path, content)` and `prepare_edit(project, path, old_text, new_text)` check everything and compute the change (`abs`, `path`, `op` create|replace|edit, `new_text`, `before_digest`, line counts, `added`/`removed`, `diff`) without writing. `edit_file` needs `old_text` exactly once (the error says how many times it was found, and what to do). Same content, empty `old_text` and `old_text == new_text` are refused. Text only: UTF-8, no NUL bytes, at most `MAX_BYTES` (1 MB) before and after.
- **Garbled text (t9):** `_check_text` (called from `_change`, so for both tools) refuses new text that has control characters (`_CONTROL`: C0 except tab, LF, CR, form feed; and DEL) the old text didn't have, more `\uD8xx`-style escape codes written as text (`_SURROGATE_ESCAPE`) than before, or a lone surrogate (it can't be encoded). The message names the code (`U+0014`) and the first line, and tells the model to write special characters as themselves. Text the file already had (an ANSI log) stays editable.
- **No halving with write_file (t9):** `prepare_write` refuses to replace a file of `SHRINK_MIN_LINES` (20) lines or more with half its lines or fewer, and points to `edit_file`. gpt-5-nano rewrote a 783-line stylesheet from memory and kept 296 lines.
- **`apply(change)`:** refuses if the nearest existing folder on the way, or the file itself, became a symlink after prepare (a folder swapped for a link would lead elsewhere). It re-reads the file and refuses if it changed (or appeared) since prepare (`before_digest`), so an approval never overwrites newer work. Writes a temp file (`.optimux-write-*`) in the same folder, fsyncs it, sets the mode (the old file's, or `0o666 & ~umask` for a new one; `_UMASK` is read once at import) and `os.replace`s it over the target. On any error the temp file is removed and the old file is untouched. Parent folders are created.
- **Display:** `diff` is a unified diff with 2 context lines, without the ---/+++ header, cut at `DIFF_LINES` (400). `describe(change)` gives the one-line label (`✎ edit site/index.html (+1 −1)`, `✎ create x.md (3 lines)`); `public(change)` is what the page gets (never `new_text`).
- **Tool schemas:** `WRITE_FILE_TOOL`, `EDIT_FILE_TOOL`, `FILE_TOOLS`, `FILE_TOOL_NAMES`. `main.run_file_tool` runs them (see main.py_AGENT.md).
- **Tests:** `tests/test_files.py`.
